## Overview

BMI Management System is a Python-based healthcare management application developed as the first project of the **Matin AI Lab Python Bootcamp**.

The purpose of this project is to practice fundamental Python programming concepts by building a real-world application that can store, analyze, and manage patient health information.

This project represents the beginning of a professional journey toward **Artificial Intelligence, Machine Learning, and Medical AI development**.

---

## Features 🚀

### Patient Management

- Add new patients
- Generate unique patient IDs automatically
- View all patient records
- Search patients by ID
- Update patient information by ID
- Delete patient records by ID
- Display patient information in a professional format


### BMI Analysis

- Calculate Body Mass Index (BMI)
- Automatically classify BMI categories:

  - Underweight
  - Normal
  - Overweight
  - Obesity


### Statistics

- Total number of patients
- Average BMI
- Maximum BMI
- Minimum BMI
- BMI category distribution


### Data Management

- Store patient information using JSON files
- Automatically save and load patient data
- Handle invalid user inputs using exception handling
- Maintain persistent patient records


### Code Quality

- Modular Python project structure
- Separation of responsibilities between modules
- Reusable functions
- Clean and maintainable code
